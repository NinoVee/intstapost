# Data model

Source of truth: `packages/db/src/schema.ts`. Migrations: `packages/db/drizzle/` (generated by
drizzle-kit, plus the hand-written `0001_immutability_guards.sql`).

```
users ─┬─ sessions
       ├─ integrations (encrypted credentials, scopes, revocation)
       ├─ media_sources ── media_assets ─┬─ media_analysis (deterministic | ai; six separate scores)
       │                                 ├─ asset_themes ── content_themes
       │                                 ├─ asset_people ── people (relationship, is_minor, exclude_from_content)
       │                                 └─ edit_versions ◀─ edit_jobs (guard result, cost)
       ├─ content_drafts ─┬─ draft_media (asset + optional edit_version, crop, trim, overlay)
       │                  ├─ draft_secondary_themes
       │                  ├─ captions (style, edited_text, tag suggestions)
       │                  ├─ hashtags
       │                  ├─ music_recommendations (deep link, best section, reason, choice)
       │                  ├─ approvals (decision + content_hash)
       │                  └─ feedback (signal + reasons + context snapshot)
       ├─ brand_profiles (settings JSON + learned JSON)
       ├─ music_preferences (artist/genre/track/playlist, per-theme weights)
       ├─ content_exclusions (asset/person/keyword/location/theme)
       ├─ publishing_targets (publishing_enabled default false, native_drafts_supported false)
       ├─ spend_ledger (per-call AI cost → daily/monthly budgets)
       └─ audit_logs (append-only)
agent_runs · schedules · trend_signals
```

## Key rules enforced in the database

| Rule | Mechanism |
|---|---|
| One copy of each original per user | `UNIQUE (user_id, sha256)` |
| Originals can't be repointed | trigger `media_assets_original_immutable` |
| Edit versions can't be rewritten | trigger `edit_versions_immutable` (only `is_final` may change) |
| Audit log is append-only | trigger `audit_logs_append_only` (allows only anonymisation on user deletion) |
| A source item is imported once | `UNIQUE (source_id, external_id)` |
| Draft media order is unambiguous | `UNIQUE (draft_id, position)` |
| Media used in a draft can't vanish | `draft_media.asset_id ON DELETE RESTRICT` |

## Enums worth knowing

- `draft_status`: generating → ready_for_review → approved → scheduled → published, plus rejected,
  saved_for_later, archived and failed. Transitions are enforced in code (`assertTransition`); the
  agent can only reach generating, ready_for_review and failed.
- `draft_kind`: `internal` (always, today) or `instagram_native` (reserved; Instagram has no draft API).
- `feedback_signal`: approved, rejected, edited, skipped, save_for_later. Rejection reasons are stored in `feedback.reasons`.
